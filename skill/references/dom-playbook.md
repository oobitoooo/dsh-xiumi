# 秀米画布 DOM 手册（2026-11 实测）

> 秀米是 AngularJS 1.x 应用；画布是**虚拟列表**（只渲染视口附近的组件），所有坐标/数量都要现查，不能缓存。

## 1. 关键 DOM

| 目标 | 选择器 |
|---|---|
| 画布页 | `.tn-page` |
| 顶层组件（一个"组件"= 一段） | `.tn-page div.tn-comp-top-level` |
| 组件内部单元格 | `.tn-cell-inst`（`tn-cell-text` / `tn-cell-image` / `tn-cell-group`） |
| 滑动组件的水平容器 | `.tn-group-horizontal-box`（`overflow-x`，`scrollLeft` 控制第几页可见） |
| 图片 | `img.tn-image-presenter`；`src` 里 `-sz_<字节数>` 是**原图指纹**（库图/上传图），模板图是 `..._sz-xxx.jpg` |
| 画布 x 范围 | 100% 缩放下组件 x≈1019，宽 383（视口宽度不同会变，用 `getBoundingClientRect()` 算） |

**图片指纹怎么用**：同一张照片，竖排组件里是 `-sz_<cards 卡片字节数>`，上传到"我的图库"的 web43 版本是 `-sz_<web43 字节数>`。
两个数都能从本地文件 `fs.statSync(file).size` 得到，因此可以精确对应"第 k 张照片 → 图库里哪个缩略图"。

## 2. 组件级操作

### 选中
- 单点组件中心 = 选中里面**最内层**的内容（图片/文本单元格），工具栏随之变化。
- 多选：点第一个 → `Shift+ArrowDown` ×(n-1)（**不是** Shift+点击，修饰键注入不可靠）。
- 布局模式（`Ctrl+/` 或页面工具栏 `[title*="布局模式"]` 图标）：点击选中"单元格"而不是内容。**Ctrl+/ 在焦点不在画布时不生效**，用 title 判断状态：`关闭布局模式…` = 当前已开启。

### 删除（唯一可靠路径）
点组件中心（真实鼠标）→ 点工具栏里 **`button.btn-danger.op-bar-btn` 中 rect 非 0 的那个**（DOM 里有个隐藏副本 rect=0，必须过滤）→ 等 1.3s。
- 普通图片/文本组件：一次删干净。
- **滑动组件：第一次只删掉内部水平组，留下 60~100px 空壳**，要再点空壳删一次。
- 键盘 Delete/Backspace 对单元格无效，别试。

### 插入模板（左栏）
左栏按钮：`.x3-tab-item`（`图文模板` / `图片素材` / `图文收藏` / `剪贴板` / `我的图库`）。
顶部品类：`a.tn-tpl-tag-lv1-child`（标题/卡片/图片/布局/SVG/组件/热门）。
菜单项：`.dropdown-menu li:visible`。
样式项：`.tn-tpl-comp-item`（必须过滤隐藏项：`w>80 && h>60 && top>80`）。

**点样式只能 JS click 根节点，且只点一次**：
```js
const items = [...document.querySelectorAll('.tn-tpl-comp-item')]
  .filter(e => { const r = e.getBoundingClientRect(); return r.width > 80 && r.height > 60 && r.top > 80; });
items[i].click();           // 一次 = 插一份；点内层节点会连插多份
```
插入落点：**当前选区的后面**（选中 N 个组件再插，组件会出现在第 N 个之后）。

### 换图（"点击图库换图"）
真实流程：选中组件里的图片单元格 → 左栏切「我的图库」→ 点目标缩略图 = 替换该单元格图片。
**缩略图必须 `scrollIntoView` 后再点**：图库面板滚动后缩略图 y 可能超出视口，`mouse.click` 会直接点空（最容易被误判成"换图失败"）。

### 上传图库
左栏「我的图库」→ 文本含 `上传图片(无水印)` 的按钮 → Playwright `filechooser`（支持多选）→ `fc.setFiles([...])` → 等 8s。
缩略图按上传顺序出现；每张的 `src` 带 `-sz_<字节数>`，与本地区块链一致（无压缩/无水印）。

## 3. 滑动（slideshow）组件专项

结构：组件 → 若干层 group → **水平容器 `tn-group-horizontal-box`** → 每页一个子组件（图片 + 可能的图注文字）。
- 页数 = 水平容器 scope 的 `cellGroupItems.length`。
- **UI 上的「设置滑动序列」按钮点不到**：它要求选中"水平容器单元格"，而容器被子页完全盖住；布局模式、点边距、点滚动条都试过，选中的永远是子页或外层 frame。
  所以改页数直接改 Angular 模型（见 `references/gallery-recipe.md`）。
- 水平滚动：`box.scrollLeft = k * box.clientWidth`，滚完等 0.7s 再取 rect。

## 4. 虚拟列表 / 其它坑

1. **不要用 `img` 数量判断插入是否成功**——视口外的节点不渲染。用"组件数量 + 组件内 `-sz_` 指纹集合"判断。
2. 每次操作后重新查 DOM 和 rect；跨操作复用坐标必然错位。
3. 撤销 `Ctrl+Z` 是**整条编辑历史**，不限于本会话：误按可能把上一位编辑者早已保存的编辑一起撤回来（曾把已删除的关注条、3 个滑动组件全撤回）。批量作业前先记录基线组件数，撤销后立刻对数。
4. 秀米保存后可能自动出 `保存成功` 提示并**自动提交分享审核**；分享页有缓存，核对时等 6~8s。
5. 保存按钮：`span.op-btn-inset-desc` 文本 `保存`（顶栏）。同一行的 `导出`/`更多` 是下拉，`更多` 里有"历史记录 / 导入 / 另存 / 生成长图"等。
6. **图库缩略图按文件名点，别只按 `-sz_` 数字 includes 匹配**：`-sz_1002` 是 `-sz_10022` 的前缀，`includes` 会点错图（实测把 5 条分割线换成了小节标题图）。要么用「提取数字后全等」，要么直接在左栏找 `.display-name` 文本等于 `xxx.png` 的缩略图再点。
7. 想改"副本"不动原稿：编辑器 `更多 → 另存一个图文`，会**直接生成新草稿并跳转到新 id**（无确认弹窗），之后所有改动都在新 id 上；核对原稿未被改可开原 id 查 `-sz_` 指纹。
